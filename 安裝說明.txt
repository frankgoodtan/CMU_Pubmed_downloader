====================================================================
一鍵安裝（最推薦，連 ID 都不用自己查）
====================================================================

這個擴充功能的 manifest.json 釘了一個固定的 "key"，Chrome 會用這個 key
算出固定的擴充功能 ID——也就是說 ID 其實不用開 Chrome 去 chrome://extensions
複製，直接從 manifest.json 算就好。一鍵安裝.bat 做的就是這件事，再加上：
  0. 用 native_host/requirements.txt 一次裝齊全部 native host 需要的
     Python 套件（opencv-python / mss / numpy / openai-whisper，不用再
     分開手動下兩三行 pip install）
  1. com.pubmed_downloader.write_love      — 人機驗證畫愛心提醒
  2. com.pubmed_downloader.file_manager    — 本地資料夾模式讀寫、debug log 留痕
  3. com.pubmed_downloader.captcha_solver  — EZproxy 重登語音驗證碼自動辨識（選用，
     見下面第三段安裝說明；沒裝的話重登入一律照舊跳出來要你手動輸入，不影響
     其他功能）

用法：
  雙擊 chrome_extension 資料夾最上層（跟這份說明文件同一層）的「一鍵安裝.bat」，
  跳出的黑底視窗會先跑 pip 安裝套件（第一次跑因為要下載 openai-whisper 連帶
  的 torch，檔案較大，需要一點時間，耐心等它跑完，不要關掉視窗），再註冊
  native host，最後按任意鍵關掉即可。

  只想重新註冊 native host、不想重跑 pip 安裝的話（例如套件已經裝過了），
  可以在 native_host 資料夾開 cmd，貼上：
      powershell -ExecutionPolicy Bypass -File setup.ps1
  只想重新安裝 Python 套件、不想動 native host 註冊的話：
      pip install -r requirements.txt

這個指令做不到、也不該做到的事：把未封裝的擴充功能自動載入 Chrome。這是
Chrome 刻意設計的安全機制（載入未簽署的 dev 擴充功能一定要使用者手動點
「開發人員模式」→「載入未封裝項目」），沒辦法、也不該用腳本繞過。所以
跑完這個腳本之後，還是要自己做這最後一步（同一個瀏覽器設定檔只需要做一次）：
  1) chrome://extensions
  2) 打開右上角「開發人員模式」
  3) 「載入未封裝項目」→ 選這個 chrome_extension 資料夾
  4) 如果之前已經載入過、只是程式碼更新了，點擴充功能卡片上的重新整理圖示即可

====================================================================
一次裝好全部 Native Messaging Host（進階：手動指定 ID）
====================================================================

如果 manifest.json 沒有 key（例如你自己改過簽名設定），或想手動指定不同
的擴充功能 ID，可以用這個指令代替上面的一鍵安裝：

  1) 取得擴充功能 ID（chrome://extensions 卡片上那組 32 碼小寫字母）。

  2) 在檔案總管打開 native_host 這個資料夾，網址列打 cmd、按 Enter，
     貼上這一行（把 你的ID 換成剛剛複製的字串）：

         powershell -ExecutionPolicy Bypass -File install_all.ps1 -ExtensionId 你的ID

  3) 看到三段「Installed native messaging host: ...」輸出代表都裝好了。

  4) 回 chrome://extensions 把擴充功能重新整理一次即可。

如果之後只有其中一個 host 需要重裝（例如只是這支 Python 腳本本身改了
路徑），還是可以只跑對應那支 install_write_love.ps1 / install_file_manager.ps1 /
install_captcha_solver.ps1，不需要每次都三個一起重裝。

====================================================================
人機驗證畫愛心 — Native Messaging Host 安裝說明
====================================================================

用途：
  PubMed PDF 批次下載器擴充功能偵測到人機驗證時，除了把驗證分頁切到
  最前景，還會呼叫這個資料夾裡的 python_write_love.bat 畫一個愛心
  當提醒動畫。這需要 Chrome 的 Native Messaging 機制，必須先在本機
  的 Windows 登錄檔（HKCU，僅影響目前使用者帳號）註冊一次，換到
  別台電腦、或同一台電腦重灌 Chrome 後都要重新做一次這個安裝。

前置需求：
  - 這台電腦要有裝 Python（命令提示字元打 python --version 或
    py --version 能看到版本號即可）。
  - 裝好 opencv-python / mss / numpy 這三個套件（python_write_love.py
    啟動後會自己掃描螢幕、比對 checkbox_template.png 找目標座標，需要
    這些套件才能執行）。用一鍵安裝.bat 會自動幫你裝（連同其他 host 需要
    的套件一起，見 native_host/requirements.txt）；不想用一鍵安裝的話
    手動跑：
        pip install -r requirements.txt
  - Chrome 已經載入這個擴充功能（未封裝／開發者模式），且已重新整理
    過，確保用的是含 nativeMessaging 權限的最新版 manifest.json。

安裝步驟：

  1) 取得擴充功能 ID
     打開 chrome://extensions，找到「PubMed PDF 批次下載器 v6」
     卡片，卡片上會有一行：
         ID: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
     （32 碼小寫英文字母）把它複製起來。

  2) 在檔案總管打開 native_host 這個資料夾，點一下網址列（路徑欄）、
     打 cmd、按 Enter — 會開一個命令提示字元視窗，而且已經站在這個
     資料夾裡，不用另外打 cd。

     接著直接貼上這一行（把 你的ID 換成剛剛複製的字串，不要加引號、
     不要加角括號）：

         powershell -ExecutionPolicy Bypass -File install_write_love.ps1 -ExtensionId 你的ID

     例如：
         powershell -ExecutionPolicy Bypass -File install_write_love.ps1 -ExtensionId ffkadoflggdodoijejjplanpfbofncaa

  3) 看到類似下面的輸出代表安裝成功：

         Installed native messaging host: com.pubmed_downloader.write_love
           manifest:  ...\com.pubmed_downloader.write_love.json
           bat:       ...\python_write_love.bat
           extension: chrome-extension://你的ID/

  4) 回 chrome://extensions 把擴充功能重新整理一次，打開 popup，
     展開「🧪 測試工具」→ 按「🧪 測試人機驗證流程」測試。
     成功的話會另外跳出一個畫愛心的小視窗，約 5 秒後自動關閉。

安裝做了什麼（供參考）：
  - 把 com.pubmed_downloader.write_love.json 這個 manifest 檔案，
    用這台電腦上的絕對路徑、你的擴充功能 ID 覆寫填好。
  - 在登錄檔寫入一筆機碼：
        HKCU:\Software\Google\Chrome\NativeMessagingHosts\com.pubmed_downloader.write_love
    值指向上面那個 manifest 檔案的絕對路徑。
  - 只寫 HKCU（目前使用者），不需要系統管理員權限，也不影響其他使用者帳號。

換到新電腦 / 重灌後怎麼辦：
  - 這個登錄檔機碼不會跟著搬（HKCU 是每台電腦、每個帳號各自獨立），
    所以只要複製整個 chrome_extension 資料夾到新電腦、載入擴充功能，
    再照上面 1)～4) 重新跑一次安裝步驟即可，路徑跟 ID 通常都會變，
    重新執行 install_write_love.ps1 就會自動抓新的路徑重寫 manifest。

解除安裝：
  同樣在 native_host 資料夾開 cmd（網址列打 cmd），貼上這一行：
      reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.pubmed_downloader.write_love" /f

疑難排解：
  - 按了「測試人機驗證流程」完全沒反應、也沒跳出愛心視窗：
    表示 native host 還沒安裝成功，回到步驟 1)～3) 重跑一次。
  - 想看詳細錯誤：chrome://extensions 該擴充功能卡片上點「service worker」
    連結開發者工具，看 Console 有沒有紅字。
  - python_write_love.bat 找不到 python：在命令提示字元打
    python --version 或 py --version 能正常顯示版本號；如果都沒有，
    要先安裝 Python 並確保有加入 PATH。
  - 跳出 ModuleNotFoundError（cv2 / mss / numpy）：代表前置需求那三個
    套件沒裝，跑 pip install -r requirements.txt 補裝即可（在 native_host
    資料夾底下）。

====================================================================
本地資料夾模式 — 第二個 Native Messaging Host 安裝說明
====================================================================

用途：
  popup 裡「本地資料夾模式」開關打開後，PDF／下載失敗筆記／進度 Excel
  不再受限於 Chrome 預設下載資料夾，而是寫到你自己選的專案資料夾（例如
  桌面上的 cancer paper）。這靠另一個 native host——python_file_manager.py
  ——做實際的檔案讀寫，一樣需要先在本機登錄檔（HKCU）註冊一次，跟上面
  「畫愛心」那個 host 是彼此獨立的兩個安裝，都裝了本地資料夾模式才會
  完整可用。

  這個 host 另外還負責「debug log 留痕」：每次正式下載（測試下載不算）
  跑完，會把這次全部的處理紀錄（哪個 worker 處理了哪篇、走了哪個平台、
  PDF 有沒有抓到、失敗原因細節…）彙整成一個 txt，寫進這個 native_host
  資料夾底下自動建立的 debug_log/ 子資料夾，檔名格式：
      debug_log_<專案資料夾名稱>_<Excel檔名>_<時間戳>.txt
  這個資料夾最多保留 20 個檔案，超過會自動砍最舊的，不需要手動清理。
  這功能跟本地資料夾模式是否開啟無關，只要這個 native host 有裝就會寫；
  沒裝的話下載流程照常，只是不會產生這份留痕紀錄。

前置需求：
  - 只需要 Python 本身（stdlib），不需要額外 pip install 任何套件
    （不像 write_love 需要 opencv-python/mss/numpy，這支只用
    tkinter/json/struct/shutil 這些內建模組）。

安裝步驟（跟上面「畫愛心」幾乎一樣，只是換一支腳本）：

  1) 取得擴充功能 ID（同上面步驟 1，跟畫愛心那個共用同一個 ID）。

  2) 在 native_host 資料夾開 cmd，貼上：

         powershell -ExecutionPolicy Bypass -File install_file_manager.ps1 -ExtensionId 你的ID

  3) 看到類似下面的輸出代表安裝成功：

         Installed native messaging host: com.pubmed_downloader.file_manager
           manifest:  ...\com.pubmed_downloader.file_manager.json
           bat:       ...\python_file_manager.bat
           extension: chrome-extension://你的ID/

  4) 回 chrome://extensions 把擴充功能重新整理一次，打開 popup，勾選
     「本地資料夾模式」→ 點「📂 選擇專案資料夾...」，能跳出 Windows 資料夾
     選擇視窗就代表裝好了。

解除安裝：
      reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.pubmed_downloader.file_manager" /f

疑難排解：
  - 點「選擇專案資料夾」完全沒反應：native host 還沒裝好，回到上面
    1)～3) 重跑一次；勾選「本地資料夾模式」但沒裝這個 host 的話，擴充
    功能會自動退回原本的 chrome.downloads 下載方式，不影響既有功能。
  - 想看詳細錯誤：native_host\file_manager_debug\ 資料夾（第一次出錯時
    才會自動建立）裡的 ERROR_*.txt。

====================================================================
EZproxy 重登語音驗證碼自動辨識 — 第三個 Native Messaging Host 安裝說明（選用）
====================================================================

用途：
  整批下載期間 CMU EZproxy 的登入 session 可能會失效（例如跑了很久、或
  cookie 被清理過），需要重新登入。第一次登入永遠是你自己手動輸入帳號、
  密碼、驗證碼；成功後帳密只存在擴充功能背景程式的記憶體裡（不會寫進
  硬碟、不會留檔案），重新載入擴充功能或關掉瀏覽器就會清空、下次要重新
  輸入。裝了這個 host 之後，同一次執行期間如果又被導回登入頁，會先自動
  抓登入頁上的語音驗證碼（螢幕上「播放語音」那個按鈕對應的音檔），交給
  這支腳本用 OpenAI Whisper（tiny 模型，離線在你自己電腦上跑，不會把
  語音檔傳到任何外部伺服器）辨識出數字，自動幫你重新登入，不用你回來
  手動輸入。

  沒有裝這個 host 的話，重登入會照舊跳出來要你手動輸入，不影響其他任何
  功能——這是完全選用的功能。

  為什麼是語音、不是圖片驗證碼：實測過用圖片辨識（樣板比對），整組 4 碼
  對的機率不到 2 成，不夠可靠拿來自動送出；同一組驗證碼的語音版本用
  Whisper tiny 模型辨識，實測準確率高很多。就算辨識偶爾出錯，也設計了
  安全網：自動送出失敗會換一組驗證碼重試（最多 3 次），還是不行就自動
  退回原本手動輸入的流程，不會無限重試、也不會讓整批下載卡住。

前置需求：
  - 這台電腦要有裝 Python（同其他兩個 host）。
  - 裝好 openai-whisper / numpy 這兩個套件（比 write_love 用的
    opencv-python/mss/numpy 重不少，因為連帶會裝 torch，大約要幾百 MB，
    第一次安裝需要一點時間）。這些套件已經合併進 native_host/requirements.txt，
    用一鍵安裝.bat 會自動裝好（連同 write_love 需要的套件一起），不用
    再分開手動下 pip；只想單獨補裝套件的話：
        pip install -r requirements.txt
  - 第一次執行時，腳本會自動從網路下載 Whisper tiny 模型檔（約 75MB），
    存進使用者設定檔底下的快取資料夾，之後執行會直接讀快取、不用再下載。

安裝步驟（跟前兩個 host 幾乎一樣，只是換一支腳本）：

  1) 取得擴充功能 ID（同上面步驟，三個 host 共用同一個 ID）。

  2) 在 native_host 資料夾開 cmd，貼上：

         powershell -ExecutionPolicy Bypass -File install_captcha_solver.ps1 -ExtensionId 你的ID

  3) 看到類似下面的輸出代表安裝成功：

         Installed native messaging host: com.pubmed_downloader.captcha_solver
           manifest:  ...\com.pubmed_downloader.captcha_solver.json
           bat:       ...\python_captcha_solver.bat
           extension: chrome-extension://你的ID/

  4) 回 chrome://extensions 把擴充功能重新整理一次即可。這個功能沒有獨立
     的測試按鈕——第一次登入照常手動輸入，等整批下載期間真的又被導回
     登入頁時，才會看到 log 裡出現「自動重登：語音驗證碼辨識為...」這類
     訊息，代表有生效。

解除安裝：
      reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.pubmed_downloader.captcha_solver" /f

疑難排解：
  - log 裡一直看到「自動重登：語音驗證碼擷取失敗」或「語音驗證碼辨識
    失敗」：native host 可能沒裝好，或 pip 套件沒裝齊，回到上面 1)～3)
    重跑一次、確認 pip install -r requirements.txt 有成功執行完。連續
    失敗 3 次會自動退回手動輸入，不影響下載繼續跑。
  - 想看詳細錯誤：native_host 資料夾底下暫時還沒有專屬的 debug 資料夾，
    可從 chrome://extensions 該擴充功能卡片點「service worker」開發者
    工具，看 Console 有沒有 "Captcha audio solver" 開頭的紅字/警告。
  - ModuleNotFoundError（whisper / torch / numpy）：pip install
    -r requirements.txt 沒裝成功，重新執行一次，注意看有沒有紅字。
